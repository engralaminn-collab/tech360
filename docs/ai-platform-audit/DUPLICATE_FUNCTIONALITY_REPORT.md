# Potential overlapping functionality

These are source/model-level observations, not claims of feature parity or recommendations to replace a system.

| Domain | Candidates | Action |
|---|---|---|
| CRM / leads | TECH360, ALO, MarketingOS, wacrm | Identify system of record, tenant boundary and consent before connector design. |
| Agent orchestration | TECH360 agents, ALO ai-workforce, MarketingOS workforce, Dify, Flowise, Ruflo, LangGraph | Compare actual tool permissions and execution/audit before selecting a single bounded orchestration path. |
| Social publishing | TECH360 social APIs, ALO marketing, MarketingOS, Postiz | Assess provider permissions and licensing; do not duplicate sends or enable unaudited publishers. |
| Local inference | existing AI adapters, MarketingOS Ollama configuration, Ollama | Verify configured runtime and model before adopting shared service. |
| Media and presentation | OpenShorts, HyperFrames, Presenter, Presenton, OBS, Kdenlive | Different use cases may coexist; compare rights, resource limits and operational cost. |
| Code analysis | REA, Ghidra, agent coding tools | Native providers complement REA; none replaces independent tests and security review. |
