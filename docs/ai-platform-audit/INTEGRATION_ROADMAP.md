# Proposed roadmap — approval required before implementation

1. Verify each repository/deployment connection, asset ownership, backup/restore and CI failures. No production actions.
2. Complete a disposable MySQL and authenticated test baseline for existing inquiry-to-delivery workflow. Establish policy gates from each approved SOW; no hardcoded new commercial terms.
3. Close the smallest real workflow gaps on the existing branch in reviewable changes with idempotency, audit and tenant-isolation tests. Preserve ALO and MarketingOS independently.
4. Evaluate CRM/communication adapters with verified official APIs, consent, signatures and no-send-by-default mode.
5. After explicit review, test REA on authorized fixtures in an isolated pinned worker; no live production data.
6. Add agent/model adapters with capability allowlists, deadlines, spend controls and human approval. No unrestricted production access.
7. Evaluate marketing/media services and licences; stage approved connectors with provenance, controls and rollback.
8. Complete deferred reference deep audits, security review, staging acceptance, recovery rehearsal and explicit production approval.

For each integration, define data and permissions, component owner, tests, version updates, monitoring, disable switch and rollback before implementation. Until those are established, cost, effort and suitability remain unknown.
